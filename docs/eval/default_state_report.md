# Default-State Report (D3)

Chunky · Traffic rules and penalties assistant · Sprint 1 · Objective 1 baseline

## Method

- **Sessions:** 12 participants each answered 3 questions from the D2 gold set using only official texts and a web search, with a 600 s limit per question. This gives 36 attempts; all of them are included.
- **Marking:** The session log records whether the participant reached the answer in the official text, not the answer itself. An attempt is marked **correct** when the participant reached the answer in the official text that the D2 answer key cites. Partial answers and answers not found are marked **incorrect**.
- **Time to a correct answer:** Median of the recorded times of the correct attempts.
- **Time overall:** Median of the recorded times of all attempts, correct or incorrect.

## Results

| Measure | Value |
| --- | --- |
| Correct attempts | 22 / 36 (61%) |
| **Median time to a correct answer** | **77 s** |
| Median time overall (all attempts) | 81 s |

**Default-state value of Objective 1: 77 s.**
